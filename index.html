    Переместить в архив?

    Позиция — не будет удалена безвозвратно. Её можно вернуть из архива в любой момент.

    admin Локальный аккаунт · данные зашифрованы

    Резервная копия

    Скачайте зашифрованный файл с реестром. Без пароля восстановить его невозможно.

    Сменить пароль

    Пароль шифрует весь реестр. После смены старые резервные копии открываются только старым паролем.

    Защита от удаления

    В приложении нет функции безвозвратного удаления. Архивирование требует пароль и всегда доступно для отмены. История изменений хранится у каждой записи.
