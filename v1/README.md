# ПРИЁМКА v1 — архив старого локального сайта

Это архив прежней локальной версии приложения. Она работает как раньше: данные хранятся в `localStorage` браузера, вход по локальному паролю, есть резервные копии, CSV, почтовые настройки и офлайн-режим.

**Не вносите сюда новые записи.** Основная база теперь центральная:

**https://45-81-253-203.sslip.io/priemka/**

## Зачем нужен архив

- открыть старые локальные данные на этом устройстве;
- выгрузить старые записи в CSV и импортировать их в новую общую базу;
- скачать или восстановить старую резервную копию;
- при необходимости синхронизировать старые данные с тем же сервером — они появятся в новом портале.

Локальные данные находятся в том же origin `ervsed.github.io`, поэтому при открытии `/v1/` старые записи и пароль остаются доступны.

## Адреса
